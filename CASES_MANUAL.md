# Руководство по управлению успешными кейсами

## Обзор
Система управления успешными кейсами позволяет демонстрировать завершенные проекты на главной странице платформы Lark Freelance. Кейсы связаны с реальными завершенными проектами и содержат подробную информацию о выполненной работе.

## Структура кейса
Каждый кейс содержит следующие поля:
- **Проект**: ссылка на завершенный проект
- **Заголовок**: краткое название кейса
- **Компания**: название компании-заказчика
- **Описание**: подробное описание проекта
- **Сроки**: продолжительность выполнения
- **Бюджет**: стоимость проекта
- **Технологии**: использованные технологии
- **Вызовы**: технические сложности
- **Результаты**: достигнутые метрики и успехи
- **Избранный**: показывать на главной странице

## Доступ к управлению
Управление кейсами доступно только для менеджеров и администраторов через раздел "КЕЙСЫ" в админ-панели.

## Создание кейса
1. Перейдите в раздел "КЕЙСЫ" → "Создать кейс"
2. Выберите завершенный проект из списка
3. Заполните все поля формы
4. Отметьте "Показывать на главной странице" для отображения
5. Нажмите "СОЗДАТЬ КЕЙС"

## Редактирование кейса
1. В списке кейсов нажмите кнопку редактирования
2. Измените необходимые поля
3. Сохраните изменения

## Удаление кейса
1. В списке кейсов нажмите кнопку удаления
2. Подтвердите удаление

## Отображение на главной странице
- Кейсы с отметкой "Избранный" автоматически отображаются в разделе "КЕЙСЫ" главной страницы
- Если в базе нет избранных кейсов, показываются демо-данные
- Максимум 4 кейса на главной странице

## Связь с проектами
- Кейсы могут быть созданы только для проектов со статусом "completed"
- Один проект может иметь только один кейс
- При удалении проекта кейс также удаляется автоматически

## Тестирование
Для тестирования системы запустите скрипт `update_cases_table.php` для создания таблицы и тестовых данных.
