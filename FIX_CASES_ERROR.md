# Исправление ошибки: таблица 'cases' не существует

## Проблема
При попытке открыть главную страницу возникает ошибка:
```
Fatal error: Table 'lark_freelance.cases' doesn't exist
```

## Решение

### Вариант 1: Автоматическое создание (рекомендуется)
1. Запустите Docker контейнеры:
   ```bash
   cd /home/vladimir/Загрузки/lark-freelance.local
   docker-compose up -d
   ```

2. Выполните скрипт обновления:
   ```bash
   cd public
   php update_cases_table.php
   ```

### Вариант 2: Ручное создание через phpMyAdmin
1. Откройте phpMyAdmin (обычно http://localhost:8080)
2. Выберите базу данных `lark_freelance`
3. Перейдите во вкладку "SQL"
4. Выполните содержимое файла `create_cases_table.sql`

### Вариант 3: Через командную строку MySQL
```bash
mysql -h 127.0.0.1 -P 3306 -u root -prootpassword lark_freelance < create_cases_table.sql
```

## Проверка
После выполнения любого из вариантов:
1. Обновите главную страницу - ошибка должна исчезнуть
2. Войдите в админ-панель как менеджер
3. Перейдите в раздел "КЕЙСЫ" - должна открыться страница управления

## Что было исправлено
- Добавлена обработка ошибок в `index.php` и `cases.php`
- Создан SQL скрипт для ручного создания таблицы
- Система теперь не падает, если таблицы нет, а использует демо-данные
